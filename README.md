# PulseStock Enterprise - Inventory Management System

PulseStock Enterprise is an advanced, real-time inventory management, analytics, and point-of-sale system built for modern businesses. It features an integrated dashboard, real-time sync, predictive AI analytics, barcode scanning, and multi-warehouse support.

## Features
- **Dashboard & AI Analytics**: View overall stock levels, total capital, and predictive stock warnings.
- **AI Chat Assistant**: Ask questions about inventory and get AI-powered insights instantly.
- **Inventory Management**: Track products across multiple warehouses (Chennai, Coimbatore, Bangalore).
- **Barcode & QR Scanning**: Built-in camera scanner to quickly locate items.
- **Sales POS**: Point of sale interface for quick checkout.
- **Reports**: Generate CSV/PDF reports on valuation and turnover.
- **Dark/Light Mode**: Switch themes seamlessly.

## Setup
Simply open `index.html` in your web browser. 
Since this is a client-side mockup for demonstration, it runs locally without any build steps or backend servers.
